# SMB Web Telemetry & Accessibility Indexer

Automated benchmarking framework for analyzing real-world web performance, accessibility barriers, DOM structure, and mail exchanger (MX) deliverability across regional service sectors.

## Features
- **Headless DOM Inspection**: Analyzes responsive tap targets, call-to-action visibility, and form efficiency.
- **RFC-Compliant DNS Handshake**: Verifies upstream MX records using redundant public resolvers (Google & Cloudflare).
- **Automated Workflow**: Executes continuous evaluations on GitHub Actions Ubuntu runners.

## Methodology
- Focuses on emerging local service providers (3 to 28 verified reviews).
- Evaluates friction points: interactive calculation tools, sticky contact affordances, and micro-funnel flows.
